# القرارات المعتمدة

## 2026-10-02 — المتطلبات التشغيلية الجديدة

- **إحداثيات العقارات:** تحفظ الإحداثيات الدقيقة داخل النظام وتستخدم للإدارة والعمليات الداخلية، بينما يعرض المستخدم موقعًا تقريبيًا فقط. لا يبدأ تطبيق ذلك على الواجهة العامة قبل إنشاء نموذج الإعلانات العقارية.
- **الإيجارات:** تبدأ المرحلة بطلبات/استحقاقات الدفع والتذكيرات فقط. الدفع الإلكتروني والإيداع البنكي يؤجلان إلى مرحلة الدفع التشغيلية.
- **تنظيف الألواح الشمسية:** تدعم الخدمة طلبًا فرديًا وجدولة متكررة. ينشأ إشعار للإدارة قبل الموعد بـ24 ساعة.
- **المهام التشغيلية:** تستخدم جدول مهام موحدًا يدعم الاستحقاق والتعيين والارتباط بكيان، مع تكرار `once` أو `daily` أو `weekly`. يستخدم Laravel Scheduler وقاعدة البيانات، بما يتوافق مع Hostinger Premium.
- **الإشعارات:** يبدأ التنفيذ بإشعارات داخلية محفوظة في قاعدة البيانات. قنوات البريد وWhatsApp تضاف لاحقًا دون تغيير نموذج المهمة.
