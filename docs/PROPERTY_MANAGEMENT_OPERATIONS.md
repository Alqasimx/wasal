# دليل تشغيل إدارة الأملاك

## الهدف

هذا القسم مخصص لموظفي وصال الذين يديرون العقارات نيابة عن الملاك. لا يفتح القسم الحجوزات، ولا يستبدل لوحة العقارات الأساسية؛ بل يعرض العقارات التي لديها اتفاق إدارة نشط أو موقوف مؤقتًا.

## مسار العمل اليومي

1. افتح لوحة **إدارة الأملاك**.
2. راجع مؤشرات الإشغال والمتأخرات والصيانة والإشعارات.
3. افتح الإشعار ثم اختر **فتح المهمة** أو **فتح السجل المرتبط**.
4. راجع الخدمات القادمة وطلبات الصيانة المفتوحة.
5. حدّث حالات الصيانة والمهام.
6. راجع الاستحقاقات المتأخرة وسجل الدفعات.
7. راجع المصروفات والتسويات التي تحتاج اعتمادًا أو سدادًا.

## ملف العقار الموحد

من قائمة **العقارات المُدارة** اختر **ملف العقار**. تعرض الصفحة:

- الاتفاقيات النشطة.
- إجمالي الوحدات والمشغول والشاغر ونسبة الإشغال.
- الرصيد الإيجاري المستحق.
- الوحدات والمستأجر الحالي.
- الخدمات القادمة.
- الصيانة المفتوحة.
- المستندات التي تنتهي خلال 60 يومًا.
- آخر المصروفات.

## المهام والتنبيهات

تظهر المهمة في الإشعارات عندما:

- تكون مرتبطة بمستخدم في `assigned_to_user_id`.
- تحتوي على موعد `due_at`.
- تكون غير مكتملة أو غير ملغاة.
- يصل الوقت الحالي إلى الموعد مطروحًا منه `notify_before_minutes`.

إذا كانت قيمة `notify_before_minutes` فارغة تعامل كصفر، أي يظهر التنبيه عند حلول الموعد. لا ينشئ النظام إشعارًا ثانيًا لنفس المهمة.

### فحص التنبيهات يدويًا

```powershell
cd C:\Projects\wasal
$php = "$env:USERPROFILE\.config\herd\bin\php84\php.exe"
& $php artisan wasal:notify-due-tasks
```

### تشغيل الأتمتة أثناء التطوير

```powershell
& $php artisan schedule:work
```

يجب ترك هذه النافذة مفتوحة أثناء اختبار التوليد التلقائي. في الإنتاج استخدم Cron لتشغيل `schedule:run` كل دقيقة بدل إبقاء عملية دائمة.


## Vite

أثناء تطوير CSS وJavaScript:

```powershell
npm.cmd run dev
```

وعند إعداد ملفات الإنتاج:

```powershell
npm.cmd run build
```

Vite لا ينشئ الاستحقاقات أو الإشعارات؛ دوره تجهيز أصول الواجهة فقط. Scheduler هو المسؤول عن الأتمتة الخلفية.

## الصلاحيات

- `property_management`: تشغيل دورة إدارة الأملاك.
- `accountant`: العمليات المالية والتقارير وفق الصلاحيات الممنوحة.
- `financial_approver`: اعتماد العمليات المالية والتسويات.
- `system_admin`: الوصول الإداري الكامل.

يجب اختبار كل دور من المتصفح قبل اعتماد الإنتاج، خصوصًا إجراءات اعتماد التسوية وتسجيل السداد وإلغاء الدفعات.
